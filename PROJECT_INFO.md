# Leaks File Manager - Менеджер организации файлов утечек

## 📋 Описание проекта

**Leaks File Manager** - это desktop-приложение на Python с графическим интерфейсом (Tkinter) для автоматизированной организации и каталогизации файлов утечек данных из различных источников (форумы, Telegram каналы).

Приложение помогает структурировать файлы по датам, категориям и источникам, автоматически создавая необходимую папочную структуру и файлы с метаданными.

## 🎯 Основные возможности

### 1. Организация файлов
- **Автоматическое создание структуры папок**: Combo / Database / Logs / Mixed
- **Сортировка по датам**: Файлы автоматически распределяются по папкам с датами в формате YYYY-MM-DD
- **Генерация readme.txt**: Автоматическое создание файлов с информацией об источнике

### 2. Работа с источниками
- **Управление списком Telegram каналов**: CSV файл с каналами и ссылками
- **Редактор источников**: Встроенный GUI для добавления/редактирования каналов
- **Быстрый выбор**: Выпадающий список для быстрого выбора источника

### 3. Обработка метаданных
- **Парсинг JSON**: Чтение экспортированных данных из Telegram
- **Автоматическое заполнение**: Дата и ID сообщения подставляются автоматически из JSON
- **Связь файл-сообщение**: Автоматическое сопоставление файлов с метаданными сообщений

### 4. Режимы работы
- **Одиночная обработка**: Обработка одного файла за раз
- **Chain Submit**: Массовая обработка всех файлов из папки
- **Автозаполнение**: Опциональное автоматическое заполнение полей

## 🎮 Использование

### Первый запуск
1. Запустите `main.py`
2. Приложение автоматически загрузит список источников из `sources.csv`
3. Укажите рабочую папку для хранения файлов (сохранится в `settings.cfg`)

### Обработка файла
1. **Выберите тип**: Combo / Database / Logs / Mixed
2. **Укажите дату**: Используйте кнопки < > для навигации по датам
3. **Выберите файл**: Кнопка "Choose File"
4. **Укажите источник**: Выберите из списка или введите вручную
5. **Укажите ссылку**: Ссылка на пост/топик
6. **Submit**: Файл будет перемещен в созданную структуру папок

### Массовая обработка (Chain Submit)
1. Загрузите JSON с метаданными через "JSON messages File"
2. Укажите источник и базовую ссылку
3. Нажмите "Chain Submit"
4. Выберите папку с файлами
5. Все файлы будут обработаны автоматически

## 📁 Структура хранения

Приложение создает следующую структуру:
```
E:\_WORK\db\
├── Combo\
│   └── 2024-01-15\
│       └── domain_or_topic_name\
│           ├── file.txt
│           └── readme.txt
├── Database\
│   └── 2024-01-15\
│       └── database_name\
│           ├── database.sql
│           └── readme.txt
├── Logs\
└── Mixed\
```

Каждый `readme.txt` содержит:
```
domain_name (для Database)
Topic name
https://t.me/channel/12345
password (если указан)
```

## 👨‍💻 Разработка

### Структура классов

**FileManagerApp** (my_classes.py):
- Главное окно приложения
- Методы создания структуры папок
- Обработка файлов (одиночная и массовая)
- Автозаполнение полей из JSON метаданных

**DictEditorApp** (menu.py):
- Меню для управления источниками
- CRUD операции с CSV файлом
- Интеграция с главным окном

**Messages** (json_reader.py):
- Парсинг JSON экспорта из Telegram
- Класс Message для представления одного сообщения
- Связывание файлов с метаданными

## 🆕 Основные нововведения

### 1. 👀 Chain Submit with Preview
**Массовая обработка файлов с предпросмотром и редактированием**

#### Возможности:
- ✅ Просмотр всех файлов перед обработкой
- ✅ Редактирование категории для каждого файла
- ✅ Изменение даты и названия папки
- ✅ Просмотр путей назначения в реальном времени
- ✅ Подтверждение или отмена всей операции

#### Как использовать:
1. Нажмите синюю кнопку **"Chain Submit (Preview)"**
2. Выберите папку с файлами
3. Проверьте и отредактируйте параметры
4. Нажмите "Process All Files"

#### Преимущества:
- 🛡️ Безопасность - видите что будет сделано
- ⚡ Гибкость - редактируйте каждый файл
- 🎯 Точность - исправляйте ошибки до обработки

### 2. 🤖 AI Filename Analysis
**Интеллектуальный анализ имен файлов**

#### Возможности:
- 🌐 Автоматическое определение доменов
- 📁 Умное определение категории (Database/Combo)
- 🏢 Распознавание названий компаний
- 🌍 Определение кодов стран
- ✨ Извлечение чистых имен доменов

#### Что определяет:
```
amazon_com_database.txt      → Database, домен: amazon
VALID_MEGA_COMBO.txt         → Combo (3 индикатора)
Germany_hotmail.txt          → Combo (страна + сервис)
https://paypal.com_leak.txt  → Database, домен: paypal
```

#### Точность:
- 99% на combo-файлах (протестировано на 96 реальных файлах)
- 3 уровня уверенности: high, medium, low
- Защита от ложных срабатываний

## 💡 Полезные советы

### Когда использовать Preview:
- ✅ Файлы разных типов (Database + Combo)
- ✅ Нужно проверить/исправить категории
- ✅ Важна точность
- ✅ Первый раз с новым источником

### Когда использовать старый Chain Submit:
- ✅ Все файлы одного типа
- ✅ Нужна максимальная скорость
- ✅ Уверены в настройках

### Как читать AI анализ:
```
[AI: Auto: Domain detected: amazon (conf: high)]
      ^     ^                ^         ^
      |     |                |         └─ Уверенность
      |     |                └─────────── Найденный домен
      |     └──────────────────────────── Причина определения
      └────────────────────────────────── Авто-режим
```

## 🐛 Известные ограничения

1. **AI не идеален** - может ошибаться, проверяйте результаты
2. **Windows only** - эмодзи могут не отображаться в консоли
3. **Кириллица** - частичная поддержка в именах файлов
4. **Прокрутка** - для 100+ файлов может быть медленно

# Chain Submit Preview - Руководство пользователя

## 🎯 Что это?

**Chain Submit (Preview)** - это улучшенная версия массовой обработки файлов, которая позволяет:
- 👀 Просмотреть все файлы перед обработкой
- ✏️ Отредактировать параметры каждого файла
- 🎨 Изменить тип (Combo/Database/Logs/Mixed)
- 📅 Скорректировать даты
- 📁 Изменить названия папок
- ✅ Подтвердить или отменить всю операцию

## 🔄 Разница между версиями

### Chain Submit (старая версия)
- ⚡ Быстрая обработка без подтверждения
- 🤖 Автоматическое применение текущих настроек ко всем файлам
- ✅ Подходит для стандартных операций

### Chain Submit (Preview) - **НОВАЯ**
- 🔍 Предварительный просмотр всех операций
- ✏️ Возможность редактировать каждый файл отдельно
- 📊 Визуальное отображение путей назначения
- ⚠️ Защита от ошибок

## 📖 Как использовать

### Шаг 1: Подготовка
1. Откройте приложение
2. Выберите базовый тип в выпадающем списке (Combo/Database/Logs/Mixed)
3. Укажите источник (Telegram канал или форум)
4. Заполните базовую ссылку на канал
5. (Опционально) Загрузите JSON с метаданными для автозаполнения

### Шаг 2: Запуск Preview
1. Нажмите кнопку **"Chain Submit (Preview)"** (синяя кнопка)
2. Выберите папку с файлами для обработки
3. Откроется окно предпросмотра

### Шаг 3: Просмотр и редактирование

#### Окно предпросмотра показывает:
```
┌─────────────────────────────────────────────────────────┐
│  📋 Preview: 3 files to process                         │
├─────────────────────────────────────────────────────────┤
│                                                          │
│  📄 file1.txt                                           │
│    Type: [Combo ▼]  Date: [2024-01-15]                 │
│    Domain/Name: [file1________________]                 │
│    → ...\Combo\2024-01-15\file1                        │
│                                                          │
│  📄 database.sql                                        │
│    Type: [Database ▼]  Date: [2024-01-16]              │
│    Domain/Name: [database_____________]                 │
│    → ...\Database\2024-01-16\database                  │
│                                                          │
├─────────────────────────────────────────────────────────┤
│  Total files: 3              [❌ Cancel] [✅ Process]   │
└─────────────────────────────────────────────────────────┘
```

#### Что можно редактировать:
- **Type**: Выберите категорию из выпадающего списка
- **Date**: Измените дату в формате YYYY-MM-DD
- **Domain/Name**: Измените название папки назначения

#### Что обновляется автоматически:
- **Путь назначения** (→ ...) - обновляется при изменении любого поля
- Показывает куда будет скопирован файл

### Шаг 4: Подтверждение
1. Проверьте все пути назначения
2. Убедитесь что типы файлов выбраны правильно
3. Нажмите **"✅ Process All Files"**
4. Подтвердите обработку в диалоговом окне

### Шаг 5: Результат
После обработки появится сообщение:
- ✅ **Успех**: "Successfully processed N files!"
- ⚠️ **С ошибками**: Показывает количество обработанных и список ошибок

## 💡 Примеры использования

### Пример 1: Изменение типа для нескольких файлов
**Ситуация**: Получили файлы, изначально помечены как "Combo", но некоторые - это базы данных

**Решение**:
1. Запустите Chain Submit (Preview)
2. Для файлов .sql измените Type с "Combo" на "Database"
3. Путь автоматически обновится: `Combo\...` → `Database\...`
4. Подтвердите обработку

### Пример 2: Коррекция дат
**Ситуация**: JSON метаданные содержат неверные даты

**Решение**:
1. В preview окне исправьте даты для нужных файлов
2. Путь обновится с новой датой
3. Обработайте файлы

### Пример 3: Переименование папок
**Ситуация**: Имя файла не подходит для названия папки

**Решение**:
1. Измените поле "Domain/Name" на более подходящее
2. Путь обновится с новым названием
3. Подтвердите

## 🎨 Интерфейс

### Цветовая индикация
- **Синяя кнопка** - новая функция (Preview)
- **Белая кнопка** - стандартная функция (старый Chain Submit)
- **Синий текст** - путь назначения
- **Зеленая кнопка** - подтверждение действия
- **Красная кнопка** - отмена

### Горячие клавиши
- **Escape** - закрыть preview окно (с подтверждением)
- **Прокрутка** - используйте колесико мыши в списке файлов

## ⚠️ Важные моменты

### Валидация
- Даты должны быть в формате YYYY-MM-DD
- Названия папок очищаются от недопустимых символов автоматически
- Пустые поля заменяются на значения по умолчанию

### Обработка ошибок
- Если файл не может быть обработан, показывается ошибка
- Остальные файлы продолжают обрабатываться
- В конце показывается сводка: успешно/с ошибками

### Безопасность
- Файлы НЕ перемещаются до подтверждения
- Можно отменить в любой момент до нажатия "Process"
- При отмене файлы остаются в исходной папке

## 🔧 Технические детали

### Автоматическое заполнение из JSON
Если загружен JSON файл с метаданными:
- **Дата** - берется из `date_unixtime` сообщения
- **ID сообщения** - подставляется в ссылку автоматически
- **Filename** - используется для сопоставления файла с сообщением

### Структура создаваемых папок
```
WorkFolder\
  └── Category (Combo/Database/Logs/Mixed)\
      └── Date (YYYY-MM-DD)\
          └── Domain or Topic Name\
              ├── [файлы]\
              └── readme.txt
```

### Содержимое readme.txt
```
Domain Name (только для Database)
Topic Name
Link to Source
Password (если указан)
```

## 🆚 Когда использовать какую версию?

### Используйте **Chain Submit** (старая версия) когда:
- ✅ Все файлы одного типа
- ✅ Даты правильные
- ✅ Названия файлов подходят для папок
- ✅ Нужна быстрая обработка

### Используйте **Chain Submit (Preview)** когда:
- ✅ Файлы разных типов (Combo + Database + Logs)
- ✅ Нужно проверить/исправить даты
- ✅ Нужно переименовать папки
- ✅ Важна точность и контроль
- ✅ Первый раз обрабатываете файлы из нового источника

## 🐛 Решение проблем

### Окно preview не открывается
- Проверьте, что выбрана папка с файлами (не пустая)
- Убедитесь, что в папке есть файлы (не поддиректории)

### Путь отображается неправильно
- Проверьте настройки рабочей папки в settings.cfg
- Убедитесь, что указан правильный тип файла

### Файлы не обрабатываются
- Проверьте права доступа к папкам
- Убедитесь, что файлы не заблокированы другим приложением
- Проверьте, что путь назначения валиден
